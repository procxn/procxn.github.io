# 历史资料全文备份

本目录存放联动计划（Project Connexion，2012–2018）历史资料的**全文备份**。网页前台（文件馆/图册等）只保留缩略内容，完整原文以本目录为准。

## 目录约定

- `documents/` —— 文字资料全文：背景文件（Background Guide）、会刊、场刊、通讯、总结、回忆文章等，Markdown 格式
- `photos/` —— 原始照片备份（与网页展示图分离，保留最高分辨率原图）

## 文件命名

`documents/<年份>-<名称>.md`，如 `2014-winter-conference-bg.md`。

## 整理规范

1. 每份文件开头保留一段元信息头：标题、写作/会议时间、来源、提供者、录入日期。
2. 正文保持原文原样录入，不做润色；明显笔误以 `[原文如此]` 标注，无法辨认处以 `[缺]` 占位。
3. 敏感个人信息（住址、电话等）录入前应征得当事人同意或作删除处理。
4. 前台收录时在 `data.js` 的对应条目填入缩略介绍，`fulltext` 字段填本目录对应文件的 GitHub 链接。
